# Рассказ 2. Почему документация уничтожила Universe 182

**Серия**: Легенды Universe 194 (Спин-офф)  
**Персонажи**: Джакс, Отдел стандартизации и документации  

Во Вселенной 182 совет директоров решился на безумный эксперимент. Они заявили: *«Хватит хаоса! Каждая физическая функция, каждая элементарная частица должна быть строго задокументирована через Swagger и OpenAPI!»*

Джакс был категорически против, но отдел стандартизации прислал 40 менеджеров и обязал инженеров внедрить строгую спецификацию:

```yaml
/physics/particles/electron:
  get:
    summary: "Move electron by 1 Planck length"
    parameters:
      - name: spin
        in: query
        required: true
        schema:
          type: string
          enum: ["1/2", "-1/2"]
    responses:
      '200':
        description: "Electron moved successfully"
      '500':
        description: "NullPointerInQuantumFieldException"
```

Каждый раз, когда в Universe 182 электрон хотел повернуться вокруг ядра атома, он обязан был отправлять валидный HTTP GET-запрос к центральному серверу документации.

Первые две минуты по земному времени всё работало идеально. Но затем на планете Земля-182 возникла первая биологическая клетка. 

Три миллиарда химических реакций в секунду отправили в сервер документации 300 триллионов парсинг-запросов.

Серверная стойка документации мгновенно захлебнулась. На экранах отладки вспыхнула фатальная ошибка:

```text
[FATAL_ERROR]: Documentation server OutOfMemoryError.
[STATUS]: 4,192,041,102 electrons stuck waiting for Swagger validation JSON.
```

Вся физика Вселенной 182 застыла. Атомы водорода не могли расщепиться, потому что схема JSON не проходила валидацию поля `mass_in_grams`. Через пять секунд вся Вселенная 182 схлопнулась в одну гигантскую Чёрную Дыру из нераспарсенных текстовых документов `.yaml`.

Джакс стоял над дымящимися руинами проекта, смотрел на кипу сгоревших инструкций и произнес свою знаменитую фразу:

— Документация — для слабых. Напишем доки — и Вселенная снова выбросит NullPointerException!
