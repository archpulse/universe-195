# Приложение B. IT-Глоссарий Вселенной №195


Не все читатели сидят на Arch Linux и компилируют кастомные ядра по пятницам! Этот гайд простыми словами объясняет все IT-термины, команды и концепции из книги и рассказов.

---

### 💻 1. Терминал и Операционные Системы

* **Linux / Arch Linux**: Операционная система с открытым исходным кодом. В отличие от Windows, в Arch Linux пользователь собирает систему сам из «кирпичиков». Считается символом гиковской гордости.
* **Hyprland / dotfiles**: Hyprland — современный тайлинговый менеджер окон для Linux, где окна раскладываются по экрану автоматически мозаикой. `dotfiles` (дотфайлы) — текстовые конфиги настройки интерфейса и программ.
* **journalctl**: Системная утилита в Linux для чтения журнала логов ядра и служб (`journalctl -k`). Через неё Archpulse заметил системный заголовок Вселенной 195.
* **sysctl**: Команда в Linux для изменения фундаментальных параметров ядра прямо в оперативной памяти «на лету» без перезагрузки.

### ⚛️ 2. Физика и Квантовые Вычисления

* **FPS (Frames Per Second)**: Количество кадров в секунду. Чем выше FPS, тем плавнее картинка в игре (60+ FPS — хорошо, 240+ FPS — киберспорт).
* **Планковское время (\(5.39 \times 10^{-44}\) с)**: Минимальный теоретический квант времени в физике. В книге интерпретируется как «фундаментальный фреймрейт реальности» (\(\approx 1.85 \times 10^{43}\) FPS).
* **Квантовый компьютер (Qubit vs Bit)**: Классический процессор работает с битами (`0` или `1`). Квантовый работает с кубитами (могут быть и `0`, и `1` одновременно). Квантовый ПК не умеет просто запускать Java или Minecraft — он решает узкие математические задачи.

### 🐙 3. Код и Разработка (Git & StackOverflow)

* **Git / GitHub**: Система контроля версий. Позволяет отслеживать историю изменений кода, создавать ветки и делиться проектами со всем миром.
* **Commit (Коммит)**: Фиксация и сохранение снимка изменений в коде с текстовым комментарием (например, `git commit -m "fix: not a bug"`).
* **Push / Pull**: `push` — отправка локальных коммитов на сервер; `pull` — затягивание изменений с сервера к себе.
* **Fork (Форк)**: Создание независимой копии/ветки чужого проекта (например, создание Вселенной 196 как форка от 195).
* **Rollback (Откат)**: Возврат системы к предыдущей заведомо рабочей версии после аварии.
* **Stack Overflow**: Самый известный сайт вопросов и ответов для программистов. **Сниппет** — фрагмент кода, скопированный оттуда без полного понимания его работы (любимый метод Майло).

### 🚨 4. Ошибки и Системные Сбои

* **NullPointerException (NPE)**: «Ошибка нулевого указателя». Происходит, когда программа пытается обратиться к объекту, которого не существует в памяти (в книге — обращение к пустоте).
* **Out-of-Memory (OOM)**: Катастрофическое исчерпание оперативной памяти, из-за которого операционная система принудительно завершает процессы (или роняет серверный кластер).
* **Deadlock (Дэдлок / Взаимная блокировка)**: Ситуация, когда два процесса ждут ответа друг от друга и оба замирают навсегда, намертво вешая систему.
* **Kernel Panic (Паника Ядра)**: Фатальная ошибка ядра операционной системы, при которой дальнейшая работа невозможно и требуется немедленная перезагрузка.

### 🌐 5. Сети, Веб и Документация

* **HTTP Header (Заголовок HTTP)**: Служебная информация, передаваемая между клиентом и сервером (например, `HTTP/1.1 200 OK` — статус успешной обработки запроса).
* **Hypervisor (Гипервизор)**: Программа верхнего уровня, позволяющая запускать и изолировать множество виртуальных машин (или Вселенных!) на одном мощном сервере.
* **LLM / ChatGPT / Context Window**: Языковая модель (Large Language Model). Контекстное окно — объем оперативной памяти модели, определяющий, сколько предыдущих сообщений диалога она помнит.
* **RFC (Request for Comments)**: Официальный технический документ, описывающий стандарты и протоколы Интернета (например, *RFC-195-COFFEE: Константа кофе*).
* **Swagger / OpenAPI / JSON / YAML**: Форматы строгой спецификации и документации для веб-сервисов. В Рассказе 2 избыточная валидация каждого электрона по Swagger уничтожила Вселенную 182.
