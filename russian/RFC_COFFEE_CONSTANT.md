# RFC-195-COFFEE: Константа кофе

**Статус:** Принят

**Авторы:** Jax, Milo, Ada (Operations)

**Дата принятия:** сразу после инцидента `v195.3-hotfix2`

## Аннотация

Этот документ фиксирует одно простое, но исторически дорогое правило проектирования миров:

> **Кофе не является необязательной зависимостью.**

В Universe 195 кофеин поддерживает не только продуктивность разумных видов, но и предсказуемость их решений, устойчивость ночных компиляций и, в исключительных случаях, целостность пространства-времени. Любая попытка удалить, отключить или «временно закомментировать» кофейную подсистему требует одобрения двух архитекторов, одного администратора эксплуатации и кофемашины с зелёным health-check.

## Предыстория

За три тысячи земных лет до настоящей версии Майло, проводя чистку устаревших элементов, выполнил:

```bash
git rm --cached physics/chemistry/elements/caffeine.sys
```

Последствия получили внутреннее название **«Великая Апатия»**:

- `Global_Human_Productivity` упал на 99.4%;
- мыслители перестали мыслить, а строители пирамид начали называть пирамиды «просто кучей камней»;
- философия была временно признана недоступной;
- кофемашина операционного этажа получила тот же уровень критичности, что и ядро гравитации.

Экстренный неофициальный патч встроил кофеин в набор фундаментальных параметров Universe 195. Патч пережил все последующие ревью, потому что у него не было ревью, а мир без него почти не пережил бы утро.

## Решение

Конфигурация каждой совместимой вселенной ДОЛЖНА включать следующий параметр:

```cpp
UniverseConfig config;

config.enableQuantumMechanics = true;
config.enableRelativity = true;
config.enableGravity = true;
config.enableRandomness = true;
config.enableChemistry = true;
config.enableCoffee = true; // RFC-195-COFFEE: MUST NOT be false.
config.enableLife = true;
```

Для дочерних миров параметр `enableCoffee` инжектируется **до Большого Взрыва**. Чек-лист провижининга Universe 196 содержит специальную пометку:

```text
[COFFEE_CONSTANT]: injected pre-bigbang ✔
NOTE: NOT LIKE IN 195!!! — Ada
```

## Операционные требования

1. Кофемашина operations-этажа ДОЛЖНА мониториться непрерывно.
2. Падение уровня зёрен ниже 15% считается инцидентом `P1`.
3. Перезапуск кофемашины допускается только после создания снапшота физики и уведомления дежурной смены.
4. Команда `git rm` в пути, содержащем `coffee`, `caffeine`, `beans` или `espresso`, ДОЛЖНА требовать подтверждения фразой:

   ```text
   Я понимаю, что вторник мне не понравился по объективным причинам.
   ```

5. Однострочные фиксы, перенаправляющие перегрузку памяти в кофеиновый буфер, могут быть одобрены постфактум, если они спасли вселенную.

## Безопасность и совместимость

Константа кофе не гарантирует хороших решений. Она лишь гарантирует, что решения будут приняты достаточно бодро, чтобы их можно было откатить.

Системы с `enableCoffee = false` считаются неподдерживаемыми. Наблюдавшиеся побочные эффекты включают:

- желание «сделать это завтра»;
- создание документации до написания кода;
- чрезмерно долгие совещания;
- спонтанную энтропию в очереди тикетов;
- философские вопросы, которые начинают перегревать гипервизор.

## Открытые вопросы

- Является ли чай альтернативной реализацией интерфейса или конкурирующей веткой?
- Сколько кофеина требуется языковой модели для искреннего «отличный вопрос»?
- Почему каждый новый разумный вид первым делом спрашивает, есть ли кофе наверху?

## Заключение

Кофе — не баг. Не временный хотфикс. Не технический долг.

Кофе — это договор между разумной жизнью и понедельником.

```text
[ROLLBACK]: FORBIDDEN
[ADMIN_NOTE]: Don't delete coffee.
```
